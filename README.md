# Text Box Dialog — мод для Geode

Простой мод для Geometry Dash на фреймворке [Geode](https://geode-sdk.org/), который:

- добавляет кнопку **«TB»** в нижнее меню главного экрана (`MenuLayer`);
- по нажатию открывает кастомное диалоговое окно (попап) со своим **текстбоксом**;
- по кнопке **OK** показывает введённый текст прямо в окне.

## Структура проекта

```
TextBoxDialogMod/
├── mod.json          # манифест мода (id, версия, зависимости)
├── CMakeLists.txt     # сборка через Geode CLI
└── src/
    └── main.cpp       # весь код: попап + хук MenuLayer
```

## Как собрать

1. Установите **Geode CLI**: https://docs.geode-sdk.org/getting-started/ (там же — установка Visual Studio / Xcode, CMake, Ninja).
2. Настройте SDK один раз:
   ```
   geode config setup
   ```
3. В папке проекта соберите мод:
   ```
   geode build
   ```
   Готовый `.geode` файл появится в `build/`, его можно закинуть в папку модов Geode (или использовать `geode build --install`, чтобы сразу поставить в игру).

## Важно перед сборкой

- **Проверьте версии в `mod.json`**. Поля `"geode"` и `"gd"` должны соответствовать вашей установленной версии Geode SDK и версии Geometry Dash. Проще всего создать новый пустой проект командой `geode new` — она сама подставит актуальные версии, — и перенести в него `src/main.cpp` из этого мода.
- **Поменяйте `id` и `developer`** в `mod.json` на свои (id должен быть уникальным, формат `com.yourname.modname`).

## Как это работает (кратко)

- `TextBoxPopup` — класс попапа, наследуется от `geode::Popup<>`. Это рекомендованный Geode способ делать сложные диалоговые окна (фон, крестик закрытия — уже готовы).
- Внутри попапа используется `TextInput` — встроенный в Geode UI-компонент для однострочного текстового поля.
- `class $modify(MyMenuLayer, MenuLayer)` — хук, который перехватывает `init()` главного меню и добавляет туда кнопку.

## Что можно доработать

- Сделать многострочный текстбокс (`MDTextArea` / `CCTextInputNode` с несколькими строками).
- Сохранять введённый текст между сессиями через `Mod::get()->setSavedValue(...)`.
- Добавить валидацию ввода (например, только цифры).

Если нужно — могу расширить пример под конкретный сценарий (например, диалог с несколькими полями, или сохранение введённого текста).
